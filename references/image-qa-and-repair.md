# 九图 QA、修补和尺寸图

## 收到九图后先做槽位映射

把回传文件映射到 S1、S3、S4、S5、S6、A1、A2、A3、A4。若用户已明确指出“图二变形”“白底重复”“缺场景图”等问题，直接处理对应槽位，不重新申请生成授权，也不回 LinkFox 重新点生成。

## 淘汰条件

任一槽位出现以下情况，只有该槽位需要补做：

- 数量、轮廓、颜色、材质、包装或配件与产品事实不符；
- 白底图出现道具、文字、尺寸信息，或场景图变成纯白底；
- 场景、卖点、细节和故事职责混淆，构图明显重复；
- A+ 实际像素不满足 `宽度×6=高度×9`；
- 出现乱码、未证实宣称、水印、尺子、尺寸线、尺寸数字或其他产品。

## 固定修补路由

1. 第一次：用 Codex 内置图像模型修补目标槽位，参考其他合格图保持产品外观、光线、背景语言和构图密度一致。
2. 第二次：只针对同一个明确问题重试。若是 `network error .../codex/images/edits` 等传输故障，保留同一提示词和参考图，不把传输故障当成提示词问题。
3. 内置模型两次仍失败：立即转 GPT 网页图像模型完成同一槽位。网页端只使用本任务确实需要的参考图。
4. 网页端仍失败：报告两次内置调用和一次网页调用的准确错误，停止该槽位；不得改用代码、HTML、SVG、Canvas、Python、拼图或设计软件画图。

同一问题总共最多三次图像通道尝试。只重做失败槽位，不整批重做已通过的图片。

## 尺寸图隔离

九张 LinkFox 图全部通过 QA 后，直接以九图的视觉语言为参考，用图像模型生成第十张尺寸图。尺寸图必须由图像模型直接完成产品排布、尺寸线、方向、单位和尺寸文字；LinkFox 不做尺寸图，任何后期叠字、拼接、拉伸或代码排版都不合规。

尺寸图完成后核对每个数字、单位、方向和对应产品对象。数字或对象错误时只重做尺寸图。十张图进入“十图待最终确认”后，只有用户说“确认十张”或“按此归档”才允许命名和归档。
