# LinkFox 270 算力配置与逐图蓝图

这份 reference 只用于“主图也需要制作”的默认任务。配置前必须已经完成资料确认和浏览器接管检查。

## 页面必须显示的状态

| 页面项目 | 必须显示 |
|---|---|
| 模型 | `Img2` |
| 分辨率 | `1K` |
| 品质 | `中品质` |
| 普通图 | 白底 1、卖点 2、场景 1、特写 1、特写白底 0 |
| A+ 类型 | 自定比例，不是高级 A+ 或普通 A+ |
| A+ 数量与比例 | 4 张，`W 9:H 6` |
| LinkFox 总数与算力 | 9 张，270 算力 |
| 尺寸图 | 不在 LinkFox，交给图像模型 |

页面显示的数字必须和回执一致。只有用户已经提供并明确验收主图，任务清单写明“已验收主图例外”时，才允许改为白底 0、LinkFox 8 张、240 算力。

## 逐图蓝图

商品信息不能只写商品简介。把每个槽位的目的、背景、构图和禁止项写清楚；同一批图不能把白底图重复成场景图，也不能把尺寸图要求混进 LinkFox。

```text
【产品事实】[产品名]；销售组合：[数量、配件、包装]；材质/颜色：[真实信息]；目标站点/语言：[信息]。
【拍摄文档应用】[文档名称/“无”]；S1、S3–S6、A1–A4 按[章节/镜头]执行；不能覆盖产品事实和禁用项。
【S1 白底主图】纯白背景；展示完整真实销售组合；[准确摆放方式]；无文字、道具、尺子或尺寸信息。
【S3 卖点图 1】突出[已证实卖点一]；[非白底构图/背景]；必须看清[部件或效果]；禁止重复 S1。
【S4 卖点图 2】展示[使用方式或已证实卖点二]；[不同于 S3 的构图/背景]；必须看清[动作或功能]；禁止白底。
【S5 细节特写】近距离展示[材质/工艺/纹理/接口]；背景为[具体背景]；只放真实可售部件；禁止完整白底套装构图。
【S6 场景图】在[真实使用地点]展示[使用情境]；产品是主体；禁止纯白背景、尺子、尺寸线和尺寸数字。
【A1 故事图】表达[品牌/礼物/使用故事]；使用[版式/背景]；与 A2–A4 不重复。
【A2 功能图】解释[核心功能或步骤]；使用[版式/背景]；只写已证实内容。
【A3 细节/内容物图】展示[材质、细节或包装内容]；使用[版式/背景]；不重复 A1/A2。
【A4 场景/决策图】展示[适用人群或场景]；使用[版式/背景]；帮助买家做决定。
【全局禁止】不得改变真实数量、颜色、轮廓、配件或包装；不得出现未经证实宣称、乱码、尺子、尺寸线、尺寸数字、水印或其他产品。
```

如果有拍摄文档，先将每个镜头映射到 S1、S3–S6、A1–A4，并保留章节/镜头编号。拍摄文档只能决定镜头、构图、背景、光线、道具和叙事顺序，不能改变数量、材质、颜色、包装、尺寸或禁用项。

## 人类点击交接

配置完成后只发送一份回执，并停在“开始生成（270 算力）”前：

```text
模型：Img2｜分辨率：1K｜品质：中品质
普通图：白底 1、卖点 2、场景 1、特写 1、特写白底 0
A+：自定比例 W 9:H 6，共 4 张
尺寸图：不在 LinkFox 制作，交由图像模型
页面总计：9 张 LinkFox 图，270 算力
状态：已停在“开始生成”前，等待使用者亲自点击
```

Agent 不点击生成，不再把“要不要我点”变成问题。使用者亲自点击、下载九张 LinkFox 图并回传后，才能进入九图 QA。
