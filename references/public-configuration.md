# 使用者自己的配置

公开 Skill 不知道你的电脑、飞书知识库、账号和归档目录。每个团队在自己的项目根目录放一份配置，Agent 开工前先读它；没有填写完整就停在“资料待确认”，不猜路径。

## 必填项目

```text
PROJECT_ROOT = [本次产品资料所在的项目文件夹]
FINAL_ARCHIVE_ROOT = [最终合格图片保存的总文件夹]
NAMING_SPEC = [命名文档链接，或“按公用默认命名”]
HUMAN_SETUP_GUIDE = [本团队首次使用者权限指南链接或本地路径]
NON_A_PLUS_ASPECT_RATIO = [默认 1:1；若本次任务明确指定其他比例，在任务状态中记录]
```

`FINAL_ARCHIVE_ROOT` 是产品成品的总根目录；每个任务必须建立 `FINAL_ARCHIVE_ROOT/<product-name>/` 作为 direct child。不要自动追加“已上架”“待处理”“历史”等状态子目录，也不要从旧案例或下载目录推测另一层目录；只有使用者在本次配置中明确指定了不同结构时才例外。

默认画幅契约：只有 A+ 四张使用 `W 9:H 6`；其余普通图和独立尺寸图使用 `NON_A_PLUS_ASPECT_RATIO`，未另行指定时为 `1:1`。如果页面有“智能品牌基因”或同类模块，颜色、字体和整体风格必须在界面里实际选择并记录，不能只写在商品提示词中。

用正常中文填写即可，不要把密码、Token 或浏览器登录信息写入配置。项目资料、正式参考图、真实尺寸、禁止出现的内容、拍摄文档和必要的下载文件只放在 `PROJECT_ROOT` 对应任务目录里。

## 配置优先级

当前使用者确认的产品事实和本次明确要求，优先于偏好卡和拍摄文档；最新实拍或开发文档优先于旧资料。偏好卡只能调整视觉风格、文案语气、拍摄文档使用方式和回执方式，不能覆盖数量、材质、颜色、包装、尺寸、270 算力、人工点击、尺寸图隔离或故障恢复预算。

## 路径和文件安全

- 不从下载目录“最新文件”猜结果；每个任务使用自己的暂存目录和明确文件清单。
- 不把私人配置、浏览器截图、账号信息、产品图片或任务日志复制回公开 Skill 仓库。
- 如果需要把规则同步给同事，更新公开仓库的 references 和 CHANGELOG；个人配置仍留在各自项目。
