# 用户偏好覆盖卡

这张卡只保存使用者明确说过并确认长期沿用的工作习惯。一次性要求写进本次任务状态，不写进这里。

```text
偏好持有人：[姓名或团队角色]
原话：[使用者明确确认的原句]
确认日期：[日期]
适用范围：[所有 Amazon 套图 / 某产品族 / 某语言站点等]
版本：[例如 1.0]

允许影响：
- 视觉风格：
- 文案语言和语气：
- 拍摄文档的使用方式：
- 回执展示方式：

不得覆盖：产品事实、真实尺寸、禁用项、270 算力、人类亲自点击 LinkFox、尺寸图隔离、图像模型限制、故障恢复预算、最终验收和归档确认。
```

没有这张卡，回执必须写：“无已确认偏好，按公用默认”。偏好与硬规则冲突时，保留硬规则并说明冲突，不擅自修改公用 Skill。
